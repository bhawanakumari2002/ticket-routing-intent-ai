# Ticket Routing – Intent AI

## Project Overview

This project uses Natural Language Processing (NLP) and Machine Learning to automatically classify customer support tickets and route them to the appropriate team.

## Dataset

The project uses a synthetic customer support ticket dataset containing different customer intents and support categories.

## Method Used

* Text preprocessing
* TF-IDF Vectorization
* Logistic Regression
* Intent Classification
* Automated Ticket Routing

## Tools & Technologies

* Python
* Pandas
* Scikit-learn
* NLP
* Jupyter Notebook

## Project Files

* `Ticket Routing.ipynb` – Ticket classification notebook
* `ticket_data.csv` – Customer ticket dataset
